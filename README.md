# Dhruvansh Aqua LLP — Corporate Website

A production-quality corporate website for **Dhruvansh Aqua LLP**, built with a **Modern Industrial Editorial** design direction.

## Brand & Visual System

- **Palette**:
  - Primary Canvas: Warm Porcelain White (`#F6F5F1`)
  - Typography & Headings: Deep Ink Navy (`#172B3A`)
  - Accent / Actions: Muted Mineral Blue (`#627F91`)
  - Architectural Borders: Cool Industrial Grey (`#DCE1E3`)
  - Contrast / Footers: Charcoal (`#252B30`)
- **Typography Pairing**:
  - Headings: `Manrope` (Google Fonts)
  - Body & UI: `Inter` (Google Fonts)
  - Technical / Eyebrows / Spec Sheets: `IBM Plex Mono` (Google Fonts)
- **Branding**: Clean typographic temporary wordmark `DHRUVANSH AQUA LLP` (designed for plug-and-play replacement once official vector mark is finalized).
- **Anti-Fabrication Compliance**: Zero invented statistics, no fake FSSAI / ISO license numbers or badges, no fictional bottle brands.

## Structure & Sections

1. **Top Bar & Navigation Header**: System operational status, typographic wordmark, responsive drawer, facility sheet trigger, and quick inquiry action.
2. **Hero Section**: Asymmetrical editorial composition, authentic cleanroom facility photography, core operational pillars (`SPEC-01`, `SPEC-02`, `SPEC-03`).
3. **Company Overview**: Concise corporate narrative, verified LLP governance panel, multi-stage water filtration infrastructure showcase.
4. **Product Portfolio**: Data-driven category filter (Packaged Drinking Water, Juice & Fruit Beverages, Carbonated Soft Drinks), asymmetric image-spec cards, format details, and category prefill enquiry triggers.
5. **Manufacturing Capabilities**: Monobloc bottling photography, 6-phase chronological workflow (Water treatment, Blending, HEPA monobloc filling, Torque capping, Optical inspection, Secondary packaging), sanitary specifications grid.
6. **Quality & Compliance**: Analytical laboratory testing protocols (Physicochemical, Microbiological, Packaging Integrity, Clean-in-Place CIP), statutory records request desk.
7. **Commercial Partnerships**: 4 B2B commercial streams (Distributors, Modern Trade, Institutional/HoReCa, Contract Packaging) and 4-step commercial onboarding process.
8. **Business Enquiry Form**: Functional B2B inquiry form with live field validation, instant Confirmation Receipt modal with reference code generation, local storage logging, and client-side inspection drawer.
9. **Footer & Legal**: Wordmark, corporate metadata, legal modals (Commercial Privacy, Terms of Supply, Quality Statement), and back-to-top navigation.

## Development & Deployment

### Run Locally
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

### Content Customization
All company information, product categories, packaging specifications, and legal text are centralized in `src/data/companyData.js`.
